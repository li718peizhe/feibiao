# 取镖电流问题分析

## 原现象

> 我的发射机构是连接皮筋的，最后是通过皮筋的力量弹射发射的。
>
> 在取镖时，如果 3508 没有电流，发射机构不能稳定取镖。
>
> 当前用开始电流和结束电流控制取镖不稳定。
>
> 实测发现：皮筋的 END 电流不能低于 2000。一旦低于 2000，3508 上去的速度就不能稳稳地接住第一发飞镖；但是后续两发飞镖，不管有没有低于 2000，都可以顺利稳稳接住。
>
> 还有一点：如果 END 电流取 2000，3508 上升机构有点低，后续两发飞镖的尾翼会被换弹机构碰到，导致取完的飞镖姿态不正。如果要不影响后续两发飞镖，END 电流就要小于 2000；但是小于 2000，第一发换弹又不稳定。
>
> 如果 START 和 END 电流取一样，3508 就会直接被皮筋带上去。

核心测试结论：**第一发取镖需要 END 电流不低于 2000mA，否则接镖不稳定；后续两发为了避免尾翼碰到换弹机构，END 电流反而需要低于 2000mA。也就是说，第一发和后续两发对 END 电流的需求是相反的，不能再用一组 START/END 参数同时满足全部取镖过程。**

---

## 一、当前代码是怎么实现取镖电流的

当前代码中，取镖上升阶段的对抗电流由两个宏控制：

```c
#define PICK_COUNTER_START_CURRENT 4000
#define PICK_COUNTER_END_CURRENT 1500
#define PICK_DART_UP_DELAY_MS 2000
```

实际计算函数是：

```c
static int16_t get_pick_counter_current(uint32_t elapsed_ms)
{
    int32_t current_range = PICK_COUNTER_START_CURRENT - PICK_COUNTER_END_CURRENT;

    if (elapsed_ms >= PICK_DART_UP_DELAY_MS)
    {
        return PICK_COUNTER_END_CURRENT;
    }

    return (int16_t)(PICK_COUNTER_START_CURRENT -
        current_range * elapsed_ms / PICK_DART_UP_DELAY_MS);
}
```

也就是说，在取镖上升的 2000ms 内，电流从 `START` 线性变化到 `END`。以当前 `4000 -> 1500` 为例：

| 时间 | 输出电流 |
|------|----------|
| 0ms | 4000mA |
| 500ms | 3375mA |
| 1000ms | 2750mA |
| 1500ms | 2125mA |
| 2000ms 后 | 1500mA |

在 `handle_release_up()` 中，取镖上升阶段执行的是：

```c
if (Dart_Data.state_timer < PICK_DART_UP_DELAY_MS)
{
    servo_set_angle(SERVO_RELEASE_ANGLE, 0);
    CAN_Cmd3508(counter_current, -counter_current, 0, 0);
}
```

所以当前方案本质上是一个**按时间线性变化的开环电流曲线**。它不看位置，也不看速度，只看 `state_timer`。

## 二、为什么 START 和 END 取一样会被皮筋直接带上去

如果 START 和 END 取一样，`get_pick_counter_current()` 就会输出一个恒定电流。恒定电流的问题是：它无法适应皮筋力随机构位置变化的过程。

取镖上升时，机构受到至少三类力：

1. 皮筋拉力；
2. 机构摩擦和卡滞；
3. 3508 给的对抗电流。

皮筋力不是恒定的。机构在不同位置时，皮筋对机构的拉动能力不同，摩擦也不同。如果只给一个恒定电流，就会出现两种情况：

- 电流偏小：前段压不住皮筋，3508 会被皮筋直接带上去；
- 电流偏大：前段能压住，但后段动作太硬，取镖姿态不自然，容易扰动飞镖。

所以 START 和 END 不能简单取一样。它们必须承担不同作用：

- `START` 负责在取镖刚开始时压住皮筋，不让机构瞬间被带走；
- `END` 负责在接近取镖末段时放掉一部分对抗力，让机构以合适速度进入取镖姿态。

从这个角度看，`START > END` 是合理的。问题不在于"是否需要两个端点"，而在于当前只有一条简单直线，太粗糙。

补充现象进一步说明：END 电流不仅影响取镖稳定性，还影响机构最后停留的高度。END 越大，对抗皮筋的能力越强，机构更容易停在偏低位置；END 越小，机构更容易被皮筋带到更高位置。第一发需要 END 高一点来接稳，后续两发需要 END 低一点来给尾翼让空间，这两个目标天然冲突。

## 三、为什么第一发和后续两发表现不一样

我认为第一发更敏感，主要有三个可能原因。

### 3.1 第一发前机构状态没有被上一轮动作整理过

后续两发之前，机构已经经历过一次完整的发射、下压、步进、取镖循环，底部位置、皮筋张力、摩擦状态都被"跑顺"了一次。

但第一发对应的取镖动作前，机构可能处在更原始、更不稳定的状态：

- 皮筋初始张力更不确定；
- 机构静摩擦更明显；
- 飞镖和取镖结构的相对位置更依赖初始装配；
- 3508 编码器学习值和机械实际位置还没有经过完整循环修正。

所以第一发会对 END 电流特别敏感，而后续两发不敏感。

### 3.2 第一发需要更准确的"末段速度"

飞镖很轻，3508 很难通过电流或速度变化判断"有没有取到飞镖"。因此取镖成功主要靠机构运动速度和姿态是否合适。

第一发如果末段速度稍快，就可能把飞镖推偏或扰动；末段速度稍慢，又可能接不住。后续两发由于步进送料和机构循环已经进入稳定节奏，对速度的容忍度更高。

这解释了为什么 END 电流在 2000mA 附近会成为关键分界点：它实际控制的是取镖末段速度，而不是单纯控制"力够不够"。

### 3.3 当前电流曲线只按时间变化，不知道机构实际走到哪里

代码假设 2000ms 时机构一定到达取镖末段，所以把电流降到 END。但如果第一发因为静摩擦、皮筋状态或初始位置导致上升速度不同，那么同样的时间点不一定对应同样的位置。

后续两发因为动作更稳定，"时间约等于位置"这个假设勉强成立；第一发则不一定成立。

## 四、我对当前现象的判断

我认为当前问题不是单纯把 START 或 END 调大/调小就能彻底解决，而是：

**取镖过程需要按取镖序号使用不同的电流曲线，而不是三次取镖共用一条 START 到 END 直线，更不能是 START 等于 END 的恒定电流。**

当前 `4000 -> 1500` 这类曲线有一个好处：前段抗住皮筋，后段让机构变柔。但它的问题是：

- 第一发的最佳 END 和后续两发相反：第一发需要不低于 2000，后续两发需要低于 2000；
- 线性下降不一定符合皮筋力变化；
- END 太低或太高都会明显改变末段速度；
- START 和 END 一样时，完全丢掉了"前段抗皮筋、后段放柔"的分工。

---

## 五、建议的调试方向

### 5.1 不建议 START 和 END 取一样

START 和 END 取一样会让电流曲线失去阶段性。根据你的实测，它会导致 3508 被皮筋直接带上去，所以这条路不建议继续。

建议继续保持：

```text
START > END
```

### 5.2 第一发和后续飞镖分开参数

既然第一发和后续两发表现不同，最好不要强行用一组参数覆盖全部。

建议先分成两组：

```c
#define PICK_COUNTER_FIRST_START_CURRENT 4200
#define PICK_COUNTER_FIRST_END_CURRENT   2100

#define PICK_COUNTER_RELOAD_START_CURRENT 3800
#define PICK_COUNTER_RELOAD_END_CURRENT   1800
```

这里的数值不是最终答案，只是建议起点。核心思想是：

- 第一发：START 高一点，先压住皮筋；END 保持在 2000mA 以上，让末段不要软到接不住；
- 后续两发：START 稍低，END 降到 2000mA 以下，让机构上升高度更高，给尾翼避开换弹机构的空间。

第一发 END 建议先试 `2100`，如果仍然接不稳，再按 `2200`、`2300` 逐步上调。

后续两发 END 建议先试 `1800`。如果尾翼仍会碰到换弹机构，再降到 `1700`；如果姿态不正但已经不碰，可以回到 `1900` 找更稳的点。

### 5.3 把线性曲线改成分段曲线

比起 2000ms 内从 START 直接线性降到 END，我更建议分三段：

```text
0 ~ 300ms：保持 START，先压住皮筋，防止机构被瞬间带上去
300 ~ 1500ms：从 START 缓慢降到 END
1500 ~ 2000ms：保持 END，让末段速度稳定
```

这样比单纯线性下降更符合你的现象：开始不能太软，末端又不能太硬。

伪代码类似：

```c
if (elapsed_ms < 300)
{
    current = START;
}
else if (elapsed_ms < 1500)
{
    current = START - (START - END) * (elapsed_ms - 300) / 1200;
}
else
{
    current = END;
}
```

### 5.4 调参顺序

建议不要同时调 START 和 END。按下面顺序来：

1. 固定 START，例如 `4000` 或 `4200`；
2. 只调 END，找第一发能稳稳接住的范围；
3. END 找到后，再微调 START，解决"一开始被皮筋带上去"的问题；
4. 最后再调中间下降时间，而不是反复改两个端点。

建议每次只改 `100mA ~ 200mA`，不要大跳。

这里的关键不是 2100 和 1800 这两个具体数字，而是方向：**第一次取镖用高 END 保证接镖稳定，后续取镖用低 END 保证机构抬高、尾翼不碰换弹机构。**

## 七、代码实现建议

当前代码只有一组：

```c
#define PICK_COUNTER_START_CURRENT 4000
#define PICK_COUNTER_END_CURRENT 1500
```

后续应该改成按取镖序号选择参数。因为 `handle_stepper_move()` 里已经按 `Dart_Data.current_dart` 区分第几次换弹：

```c
case 1: target_pos = STEPPER_RELOAD_POS_1; break;
case 2: target_pos = STEPPER_RELOAD_POS_2; break;
case 3: target_pos = STEPPER_RELOAD_POS_3; break;
```

所以取镖电流也可以按 `current_dart` 区分。建议语义如下：

```text
current_dart == 1：第一次换弹/取镖，用 FIRST 参数，END >= 2000
current_dart == 2 或 3：后续换弹/取镖，用 RELOAD 参数，END < 2000
```

伪代码：

```c
static int16_t get_pick_counter_current(uint32_t elapsed_ms)
{
    int16_t start_current;
    int16_t end_current;

    if (Dart_Data.current_dart == 1)
    {
        start_current = PICK_COUNTER_FIRST_START_CURRENT;
        end_current = PICK_COUNTER_FIRST_END_CURRENT;
    }
    else
    {
        start_current = PICK_COUNTER_RELOAD_START_CURRENT;
        end_current = PICK_COUNTER_RELOAD_END_CURRENT;
    }

    return pick_current_curve(elapsed_ms, start_current, end_current);
}
```

这里最好注意一点：不要把它理解成"第一发飞镖"和"后续飞镖"的发射序号，而应该理解成**第一次换弹取镖**和**后续换弹取镖**。代码里正好可以用 `current_dart == 1` 表示第一次换弹后的取镖阶段。

## 八、最终建议

短期不要做复杂闭环，先把当前"一条线性电流"改成"分飞镖 + 分段电流曲线"。

我建议的控制策略是：

```text
第一发取镖：高 START，END 保持在 2000mA 以上，保证第一发末段有足够承托力
后续取镖：稍低 START，END 降到 2000mA 以下，让机构抬高，避免尾翼碰换弹机构
电流曲线：先保持，再下降，再保持，不要从一开始就线性下降
```

这比单纯调 START/END 两个点更稳，也符合你现在测到的现象：第一发需要 END 高一点来接稳，后续两发需要 END 低一点来避开尾翼干涉，恒定电流会被皮筋直接带上去。

## 九、多维深度分析（补充视角）

以下从多个维度对问题进行发散分析，部分观点与前述分析互为补充，部分提出不同的解释路径和解决思路。

### 9.1 机械维度：皮筋不是线性弹簧，静摩擦不是常数

#### 9.1.1 皮筋的非线性力学特性

皮筋（天然橡胶或合成橡胶）的力学行为远比"拉力随伸长量线性增加"复杂：

- **应变硬化（Strain Hardening）**：皮筋在接近最大伸长时，刚度急剧增大。取镖起始阶段机构处于最低点，皮筋伸长量最大，此时皮筋力远大于中段和末段。这意味着 START 电流需要对抗的不仅仅是"比 END 大一点"的力，而可能是数倍于 END 位置的反力。

- **迟滞回线（Hysteresis）**：皮筋的加载曲线和卸载曲线不重合。取镖过程是皮筋收缩（卸载），发射下压是皮筋拉伸（加载）。同一位置、同一伸长量，卸载时的拉力低于加载时。这意味着：第一次取镖（皮筋从初始安装状态开始卸载）和后续取镖（皮筋已经历过发射-下压-取镖的完整加卸载循环）的力曲线是不同的。**这是"第一发和后续两发表现不同"的机械层面根源之一，而不仅仅是机构是否被"跑顺"。**

- **应力松弛（Stress Relaxation）**：皮筋在恒定伸长下，拉力会随时间衰减。如果机器在比赛前长时间处于待机状态（机构在某个位置，皮筋维持一定伸长），皮筋力已经比刚安装时低。第一发取镖时的皮筋力可能因为静置时间长而偏低，后续取镖因为连续动作没有松弛时间，皮筋力反而更高。**这和直觉"第一发应该更难"相反，提示我们：第一发的 END 需要更高，可能是因为皮筋力偏低导致机构上升过快（皮筋拉力小→同样的对抗电流下机构更容易被皮筋带上去→到末段速度太快→接不稳飞镖），而不是因为皮筋力更大。**

- **Mullins 效应（应力软化）**：橡胶材料在第一次拉伸到某个幅度后，后续拉伸到相同幅度时应力会降低。这在第一次发射循环中尤为明显——皮筋经历过第一次极限拉伸后，力学特性永久性改变。第一发取镖面对的可能是"未软化"的皮筋，其刚度更高，力-伸长曲线的形状不同。

- **温度敏感性**：橡胶弹性模量对温度敏感。比赛现场（可能较热的场馆）和调试环境（可能较凉的实验室）之间，皮筋刚度可以有 10%~20% 的差异。这意味着在实验室调好的参数，到现场可能偏移。

#### 9.1.2 静摩擦与动摩擦的切换

机构从静止到运动的瞬间，静摩擦力突变为动摩擦力，摩擦力下降 20%~50%。这造成一个阶跃式的净力变化：

```text
静止时：F_net = F_rubber - F_motor - F_static
启动后：F_net = F_rubber - F_motor - F_dynamic
```

由于 F_static > F_dynamic，启动瞬间净力突增，机构可能产生一个"弹射式"的初速度。第一发时静摩擦最大（机构静止时间最长），这个效应最显著。这可能是第一发对 END 特别敏感的另一个原因：如果初始速度已经偏快，到了末段（END 阶段）就更难控。

#### 9.1.3 换弹机构位置差异——可能被忽略的关键变量

`handle_stepper_move()` 中，三次换弹的目标位置是不同的：

```c
case 1: target_pos = STEPPER_RELOAD_POS_1; break;
case 2: target_pos = STEPPER_RELOAD_POS_2; break;
case 3: target_pos = STEPPER_RELOAD_POS_3; break;
```

如果换弹机构（步进电机驱动的送弹结构）在三个位置时，其物理结构件（例如推弹板、弹仓导轨、限位块）在空间上处于不同高度，那么尾翼是否会碰到换弹机构，不仅取决于 3508 上升机构的高度，还取决于**换弹机构本身在当前位置下占用了多少空间**。

一个值得验证的假设：**STEPPER_RELOAD_POS_1 对应的换弹机构物理位置恰好处于较低处，给尾翼留出了更多空间，所以第一发即使 END=2000（机构偏低）也不会碰尾翼。而 POS_2 和 POS_3 对应的换弹机构位置较高，侵入了尾翼的运动包络，所以 END 必须小于 2000（机构必须更靠上）来避开。**

如果这个假设成立，那么问题就不是"第一发和后续两发对 END 的要求天然相反"，而是"换弹机构在三个位置对尾翼空间的占用不同，恰好 POS_1 空间大、POS_2/3 空间小"。这种情况下，参数按 `current_dart` 区分是正确的，但理解问题的本质有助于避免未来换了 STEPPER 位置后问题再次出现。

### 9.2 控制维度：开环电流控制本质上是在"盲操"

#### 9.2.1 当前控制方式的本质

当前方案用一个按时间线性变化的电流值去驱动 3508，完全不读取 3508 的编码器反馈。这等价于：

```text
给定一个开环力矩曲线，期望机构按照某个隐含的运动轨迹运动。
```

但机构的实际运动轨迹取决于：

```text
实际加速度 = (电机力矩 - 皮筋力 - 摩擦力 - 其他扰动力) / 等效惯量
```

而皮筋力随位置变化、摩擦力随速度和方向变化、扰动力（飞镖接触力、机构碰撞力）不可预知。同一条电流曲线，在不同初始条件、不同皮筋状态、不同摩擦状态下，产生的位置轨迹和速度轨迹是不同的。

**所以 END 电流不是一个"力参数"，而是一个间接的"位置参数"**——它通过力平衡决定了机构的稳态停留高度。用电流控制位置，本质上是用了一个开环的、受扰动的、非线性的映射关系。

#### 9.2.2 线性斜坡 vs 最小加加速度轨迹

从运动平滑性角度，线性电流斜坡并不是最优的。机构的运动质量（是否稳定接住飞镖）很大程度上取决于末段速度的一致性和平稳性。如果希望末段速度平缓趋近于零（软接触），电流曲线应该设计成"加速度连续"的 S 形曲线（加加速度限制），而不是线性斜坡（加速度为常数，加加速度在起点和终点为无穷大）。

线性斜坡在起点（电流开始下降）和终点（电流停止下降）处有一个隐含的"拐角"——电机力矩变化率突变，对应机构加速度突变，可能激发机构弹性振动。对于轻质飞镖，这种振动足以改变飞镖在取镖瞬间的姿态。

#### 9.2.3 为什么不建议直接上闭环

前面提到"短期不要做复杂闭环"，这个判断我认同。但值得说清楚为什么：

- **3508 的编码器分辨率有限**，且取镖过程涉及飞镖这种轻质负载的接触检测，力控比位控更合适；
- **飞镖接触是一个不可建模的扰动**，闭环位置控制可能在接触瞬间产生很大的恢复力，反而把飞镖弹开；
- **纯闭环可能引入振荡**，如果机构+皮筋的固有频率和闭环带宽接近，容易共振。

但如果未来要演进，最值得加的不是位置闭环，而是**速度观测 + 电流前馈**：用编码器差分得到速度，在末段对速度做限幅（速度太快时自动增加对抗电流），相当于一个软的速度上限保护。这比位置闭环风险低，收益明确。

### 9.3 电机物理维度：3508 电流-力矩关系并非理想线性

#### 9.3.1 低速下的力矩脉动

3508 是无刷直流电机（BLDC），在低速运行时存在齿槽转矩（Cogging Torque）——即使电流恒定，力矩也会随转子位置波动。取镖过程的末段速度较低，齿槽转矩的波动可能占到总力矩的 10%~20%，表现为机构的"爬行"或"抖动"。END 电流越低，电机力矩越小，齿槽转矩的相对影响越大。这可能解释为什么 END 太低时第一发接不稳：不是平均力不够，而是力矩波动导致末段运动不够平滑。

#### 9.3.2 电流-力矩的非线性区

3508 在小电流区间（如 < 1000mA 等效转矩），由于逆变器死区、摩擦转矩占比增大等原因，力矩输出可能不再与电流设置值成良好线性关系。如果 END 电流降到了这个非线性区，实际力矩可能比预期的小或波动大。建议通过编码器速度曲线验证：给定恒定小电流时，机构是否匀速运动。如果出现明显的速度波动，说明 END 不应设置在这个区间。

#### 9.3.3 电机发热对力矩常数的影响

连续运行后 3508 温度升高，永磁体磁性减弱（可逆），力矩常数 Kt 下降。同样的电流产生的力矩变小。这意味着：

- 第一发取镖：3508 处于冷态，Kt 正常；
- 第三发取镖：3508 已经历多次大电流动作，温度升高，Kt 下降，同样电流产生的对抗力矩偏小。

这提供了一个与直觉相反的推论：**如果电机发热导致力矩下降，后续取镖的实际对抗力矩会比电流值暗示的更小，机构会更容易被皮筋带上去（更高）。这恰好是后续取镖所期望的（机构更靠上，避开尾翼）。但也意味着，如果冷态调参刚好，热态可能 END 已经"不够"了。**

### 9.4 系统集成维度：与发射状态机、裁判/视觉流程的耦合

#### 9.4.1 取镖电流和时间如果被其他任务打断

`shoot_task` 运行在 FreeRTOS 任务中，如果存在更高优先级的任务抢占，`state_timer++` 的累积可能与实际时间出现偏差。线性的电流-时间曲线对时间精度敏感，10ms 的偏差就意味着 15mA 的电流偏差（以 4000→1500/2000ms 为例，每毫秒变化 1.25mA，这个量级影响不大）。但如果存在更大时间偏差（比如 USB 中断阻塞了任务调度），影响会放大。

#### 9.4.2 3508 电流命令被其他状态覆盖

在取镖上升阶段（`handle_release_up()` 中 `state_timer < 2000ms` 时），电流由 `get_pick_counter_current()` 计算。但如果在此期间有其他条件（例如某个保护逻辑）重新调用了 `CAN_Cmd3508()`，取镖电流就会被覆盖。建议检查是否存在这种情况——比如步进电机运动期间是否会意外触发 3508 命令。

#### 9.4.3 视觉/裁判失联场景下的取镖行为

结合《失联解决方法》中描述的场景，如果取镖过程中发生了 RC 或裁判失联，当前的 `handle_release_up()` 是否有保护逻辑会中断或改变 3508 电流？如果存在这样的逻辑，取镖电流曲线可能在中途被打断，导致机构停在一个非预期的位置。

### 9.5 比较维度：同类机构的设计参考

#### 9.5.1 其他 RoboMaster 飞镖发射机构的常见做法

RoboMaster 比赛中，使用皮筋蓄力 + 电机控制的飞镖发射机构并不是孤例。常见的工程实践包括：

- **双电机差速控制**：用两个电机分别控制上升和下压，避免单电机频繁换向；
- **电流查表（LUT）**：不靠线性公式计算，而是预先根据位置标定一条电流曲线，实测每个位置需要的对抗电流；
- **机械限位 + 电流保持**：在取镖末段加一个机械限位（软胶垫），取镖到位后不靠电流对抗皮筋，而是靠在机械限位上保持小电流。这样末段高度由机械确定，不依赖电流精调；
- **皮筋预紧可调**：皮筋的固定端不直接固定在机架上，而是通过一个可调螺丝/滑块固定，可以通过调节皮筋预紧力来改变力曲线，避免完全依赖软件参数。

#### 9.5.2 机械层面的"根治"思路

从系统设计角度看，当前问题是：**一个机械平衡位置（取镖末段高度）完全依赖一个开环电气参数（END 电流）来维持**。这种设计本身对扰动敏感。如果要根治，最稳健的方式是从机械上给取镖末段加一个确定的、可重复的定位参考，例如：

- 一个可调机械挡块（hard stop），让机构在取镖末段靠在挡块上，电流只负责"推着机构靠住档块"，不负责"决定位置"；
- 或者一个可调预紧的弹簧/皮筋对机构施加一个偏置力，让机构在取镖末段始终靠在某个参考面上。

这样 END 电流就从一个"位置决定参数"变成了"可靠性保障参数"（确保机构靠住），参数敏感性大幅降低。

### 9.6 认知维度：几个值得验证的假设

以下假设如果验证了，可能改变参数调优的方向：

#### 9.6.1 "第一发 END 不能低于 2000"可能是皮筋状态的函数

如果皮筋刚换过（较紧），或者皮筋使用较久（较松），2000 这个阈值是否会漂移？建议在不同皮筋状态、不同环境温度下复测这个阈值。如果阈值漂移大，说明 END 电流不适合作为固定宏，而应该设计成一个可标定的变量。

#### 9.6.2 "后续两发尾翼碰到换弹机构"可能与步进电机位置精度有关

步进电机存在丢步风险。如果 STEPPER_RELOAD_POS_2 和 POS_3 的实际到达位置和预期有偏差（例如差了几十个脉冲），尾翼干涉的风险就会变化。建议验证步进电机在三个位置的实际重复定位精度，并确认位置传感器（如果有）的读数是否一致。

#### 9.6.3 上升速度可能比 END 电流本身更关键

取镖成败的物理本质是：飞镖被取的瞬间，机构的运动速度、加速度和位置是否在"飞镖可以接受的范围内"。END 电流只是间接影响末段速度的手段。如果存在方法直接测量或估算机构速度（例如用 3508 编码器做差分），并把"速度是否符合预期"作为调参的反馈量，会比盲调电流高效得多。建议在调试阶段加一个速度监控——用 CAN 回读 3508 的速度，通过串口或日志输出，观察不同 END 参数下末段 200ms 的速度变化。

#### 9.6.4 飞镖本身的差异

三发飞镖在弹仓中的位置不同，受到的弹簧压力不同，出仓阻力不同。第一发飞镖在弹仓最上方，弹簧压力最小，出仓最顺滑，但也最容易因为振动而松动。后续飞镖弹簧压力更大，出仓阻力更大，需要更大的机构托举力。这提供了一个与当前参数方向相反的推论：**后续飞镖因为出仓阻力大，理论上需要更大的托举力（更高的 END），但实测却发现后续需要更低的 END（让机构更高）。这表明"尾翼避开换弹机构"这个约束压倒了"托举力足够"的需求，所以后续飞镖的瓶颈不是托举力，而是几何干涉。**

### 9.7 综合判断与分层建议

#### 9.7.1 问题层次图

```text
表象层：第一发需要 END≥2000，后续需要 END<2000，一组参数不够
    ↓
直接层：END 电流决定了取镖末段机构的力平衡高度
    ↓
机制层：第一发和后续在三个维度上不同——
        ① 皮筋力状态（未循环 vs 已循环）
        ② 摩擦状态（静摩擦大 vs 已跑顺）
        ③ 换弹机构几何位置（POS_1 vs POS_2/3 空间占用不同）
    ↓
根因层：取镖机构缺乏机械定位参考，其末段高度完全依赖开环电流平衡皮筋力
```

#### 9.7.2 分层建议

| 层级 | 方案 | 成本 | 收益 | 建议优先级 |
|------|------|------|------|------------|
| 软件参数 | 按 current_dart 分开电流曲线 + 分段斜坡 | 低（改几个宏和函数） | 中（大概率解决当前现象） | **立即执行** |
| 软件策略 | 增加编码器速度监控，末段速度超限时自动补电流 | 中（需要编码器读取和速度计算） | 高（从根本上提升取镖一致性） | 短期跟进 |
| 机械辅助 | 增加取镖末段机械限位（硬挡块/软胶垫） | 中（需要加工和装配） | 很高（消除对电流参数的敏感依赖） | 中期优化 |
| 系统重构 | 3508 取镖增加位置闭环或速度闭环 | 高（需要调试闭环参数，有震荡风险） | 高（运动鲁棒性大幅提升） | 长期演进 |

#### 9.7.3 对当前调参的补充建议

在前述"分飞镖 + 分段曲线"的基础上，补充几点：

1. **用一个调试变量代替宏**：先不要用 `#define` 写死参数。用一个可以通过串口/DBus/调试工具实时修改的变量，在现场连续测试不同 END 值，快速找到第一发和后续的各自最佳范围。确定后再固化为宏。

2. **重点关注末段 300ms 的速度**：如果条件允许，用 CAN 回读 3508 速度。取镖成败的物理量是末段速度——太快会撞飞飞镖，太慢会接不住。END 电流应该调到"末段 300ms 内机构上升速度稳定且缓慢（接近匀速）"的状态，而不是盲目追求某个电流数值。

3. **注意皮筋老化漂移**：在当前皮筋状态下调好的参数，建议在皮筋使用 50 次、100 次、200 次后分别复测，确认参数是否需要跟随皮筋寿命调整。

4. **先验证"换弹机构位置假说"**：手动将步进电机分别移动到 POS_1、POS_2、POS_3，在不通电的情况下手动推动取镖机构到不同高度，确认尾翼在不同 STEPPER 位置下的实际空间裕量。如果证明确实是 POS_2/3 空间小，那么合理；如果不是，说明问题另有原因（比如皮筋循环效应比几何效应更主导）。

5. ~~**考虑增加一个"第一发预处理"动作**~~（已否决）：这个想法的原始思路是——在正式取第一发之前，先执行一次空的取镖-复位循环（不装飞镖），让皮筋和机构完成一个"热身"循环，消除静摩擦和皮筋初态的不确定性，之后第一发和后续飞镖的状态就更接近了，参数也许可以统一为一组。

    **但是闸门有 30 秒时间限制，加一次完整空循环来不及。** 而且进一步想：第一发的下压动作（`handle_down_movement`）本身就会把皮筋拉到极限伸长，实质上已经完成了一次加载循环。如果下压之后再取镖仍然表现出"第一发和后两发不同"，说明这个差异不是单纯靠"多跑一次"能消除的，更可能是换弹机构几何位置或皮筋迟滞回线的内在属性。

    **替代思路**：与其增加预处理循环，不如把"打破静摩擦"的动作融入到第一发取镖本身的电流曲线里——具体做法是，在第一发取镖的前 200~300ms 内，先给一个略高于 START 的短脉冲电流（例如 5000mA 持续 150ms），然后回到正常 START 再开始下降。这个短脉冲的作用不是"对抗皮筋"，而是"把机构从静摩擦中震出来"，同时不消耗额外的时间窗口。这比一次完整空循环省时得多，且效果可验证。

## 十、结合后续看法后的最终解决建议

综合现在所有现象，我认为最终结论很明确：

**不要继续寻找一组统一的 START/END 电流。第一发取镖和后续两发取镖的需求相反，必须分开控制。**

具体原因是：

- 第一发取镖：`END < 2000mA` 会导致接镖不稳，所以第一发需要 `END >= 2000mA`；
- 后续两发取镖：`END = 2000mA` 会让机构偏低，尾翼被换弹机构碰到，所以后续需要 `END < 2000mA`；
- START 和 END 取一样时，电流曲线失去前后阶段差异，机构会被皮筋直接带上去，不能采用恒定电流。

因此最终软件方案应该是：

```text
第一次换弹取镖：一套电流曲线，重点保证接镖稳定
后续换弹取镖：另一套电流曲线，重点保证机构抬高，避开尾翼干涉
```

### 10.1 第一版建议参数

先用下面这组作为起点：

```c
#define PICK_COUNTER_FIRST_START_CURRENT 4200
#define PICK_COUNTER_FIRST_END_CURRENT   2100

#define PICK_COUNTER_RELOAD_START_CURRENT 3800
#define PICK_COUNTER_RELOAD_END_CURRENT   1800
```

解释：

- `FIRST_END = 2100`：略高于 2000，优先保证第一次换弹取镖稳定；
- `RELOAD_END = 1800`：低于 2000，让后续两次取镖机构抬得更高，避免尾翼碰换弹机构；
- `FIRST_START > RELOAD_START`：第一次换弹更容易受静摩擦、初始状态影响，所以前段给更强的对抗电流；
- `START > END`：保留"前段压住皮筋，末段释放高度"的阶段性，避免恒定电流导致机构被皮筋直接带走。

### 10.2 电流曲线不要再用单纯线性下降

建议把取镖电流改成三段：

```text
0 ~ 300ms：保持 START，先稳住机构
300 ~ 1500ms：从 START 平滑降到 END
1500 ~ 2000ms：保持 END，让末段姿态稳定
```

这样比当前从 0ms 开始一路线性下降更稳。开始阶段不会太软，末段也不会因为继续下降而突然改变姿态。

如果第一发仍然存在静摩擦卡住或突然释放，可以只给第一次换弹加一个很短的启动脉冲：

```text
0 ~ 120ms：FIRST_START + 500mA
120 ~ 300ms：FIRST_START
后续按正常三段曲线
```

这个脉冲只作为备选，不建议第一版就加。先验证普通三段曲线。

### 10.3 代码实现方向

用 `Dart_Data.current_dart` 区分当前是哪一次换弹取镖：

```text
current_dart == 1：第一次换弹取镖，使用 FIRST 参数
current_dart == 2 或 3：后续换弹取镖，使用 RELOAD 参数
```

不要再让 `get_pick_counter_current()` 只依赖全局的 `PICK_COUNTER_START_CURRENT` 和 `PICK_COUNTER_END_CURRENT`。它应该先选参数，再计算分段曲线。

### 10.4 调参顺序

不要同时调四个参数。建议按这个顺序：

1. 固定 `FIRST_START = 4200`，只调 `FIRST_END`，目标是第一次换弹取镖稳定。范围从 `2100` 开始，按 `+100mA` 调。
2. 固定 `RELOAD_START = 3800`，只调 `RELOAD_END`，目标是后续两发尾翼不碰换弹机构。范围从 `1800` 开始，按 `-100mA` 调。
3. 如果第一发一开始就被皮筋带动，再提高 `FIRST_START`，不要先动 `FIRST_END`。
4. 如果后续机构抬太猛导致姿态发飘，再提高 `RELOAD_END`，不要先动 `RELOAD_START`。
5. 最后再调三段曲线的时间点，例如把 300ms 改成 400ms，或者把 1500ms 改成 1600ms。

### 10.5 判断标准

每组参数至少连续测 5 次，不要只看单次。

第一发取镖合格标准：

```text
第一次换弹取镖能稳定接住
飞镖姿态不歪
机构没有被皮筋突然带上去
```

后续两发取镖合格标准：

```text
尾翼不碰换弹机构
取完后飞镖姿态正
机构上升过程不突然加速
```

整套流程合格标准：

```text
第一发、第二发、第三发换弹取镖都稳定
不因为 END 参数妥协导致另一类问题复现
```

### 10.6 最终优先级

我建议按这个优先级处理：

1. **立即做**：分第一次换弹和后续换弹两套 START/END 参数。
2. **立即做**：把线性电流改成三段电流曲线。
3. **调试做**：记录 3508 上升末段速度，观察 END 改变时末段速度和姿态的关系。
4. **中期做**：检查 POS_2/POS_3 下尾翼和换弹机构的机械间隙，必要时调整步进位置或让位结构。
