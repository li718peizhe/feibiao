## 第一阶段：接线与电气确认

由硬件同学依据已接好的实物填写下表，无需照旧文档重新接线。

| 项目 | 必须记录的结果 |
|---|---|
| 电磁铁 | 当前型号、额定电压和电流、接线极性、允许连续通电时间或工作占空要求 |
| 继电器模块 | 型号、供电电压、输入高/低电平触发、3.3 V 控制是否可靠 |
| 触点 | 实际使用 COM–NO 还是 COM–NC；继电器失电时磁铁是否断电 |
| 控制引脚 | 是否为 `pwm_tim1_ch3`、PE13、C 板 PWM 第 3 列 C3；信号参考地是否正确 |
| 线圈保护 | 实际保护器件及极性与当前磁铁、模块是否匹配 |
| 实测对应关系 | 输入低/高/悬空、控制板复位时，继电器触点、磁铁电压和吸持/释放现象 |

以断开磁铁负载的继电器测试开始，再按当前型号额定条件测试磁铁。旧 ELE-P20/15 的 24 V、0.1 A、无极性及长时间通电测试不能作为本磁铁的参数。

**阶段出口：** 形成“逻辑动作 → 磁铁通断 → 继电器触点 → 控制电平”对应表。若实物与通电消磁记录不符，停止该适配并更新事实；3.3 V 触发不可靠或悬空误动作时，把 `kMagnetInstalled` 改回 false 并报告。

## 第四阶段：现场单独台架验收

烧录前提醒一次：烧录会复位、电机会松开，手离开夹爪，上着膛先退膛。用有支承的小铁片检查磁铁，不启动自动换弹或发射。看 C 板 USB 串口日志。

1. **上电与复位：** 上电后继电器不吸合（模块指示灯不亮），磁铁吸住铁片；按复位键时也不吸合。跳线保持 L；烧上新固件后一上电就吸合，说明电平反了，断电后把 `kMagnetRelayActiveHigh` 改回 true 重编。
2. **手动切换：** 右拨杆中位、左拨杆下位，摇杆保持中位；拨轮负向保持 2 s，继电器吸合、铁片掉下，日志“电磁铁通电消磁命令”。不切回，3 s 后继电器自己松开、重新吸住，日志“电磁铁通电满 3.0 s，自动断电吸持”。再切一次通电，马上回中再拨下保持 2 s，应在 3 s 到点之前就断电，日志“电磁铁断电吸持命令”。
3. **异常状态：** 通电期间切无力（右拨杆下）或关遥控器，继电器应立即松开，日志“无力或故障，电磁铁断电吸持”。
4. **重复验证：** 连续切换 10 次，记录误动作、粘连和释放延迟；之后摸磁铁外壳，不烫手就保留 3 s，烫手就调小 `kMagnetOnLimit`。

**停止条件：** 意外通电、触点粘连、释放失败、异常发热、复位误动作。现场断电后磁铁仍会吸住铁片，这是正常的。
