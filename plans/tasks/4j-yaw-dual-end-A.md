# 4j yaw 自动找两端并回中：独立方案 A

2026-11-24；主对话 item 5。用户最新授权目标：自动找左右终点，自动回中，合入现有自动回零。本文为A草稿，尚未读取本轮B；旧单端定稿冻结并停止执行。

## 设计选择

采用专用纯逻辑 `YawAxis`，驱动适配仍复用 MotorPort/RMMotor；不把两端学习功能塞进所有轴共用的 MotorAxis 回零路径。累计转子计数为运动依据，中点为两端计数均值，不再依赖12度、旧销轴半径或视觉36000系数。两个机械端点之间的行程中点不一定等于发射方向的正前方，日志称“行程中点”。

现有 `LauncherHardware` 内 yaw 的 Axis() 使用点需逐项切换到专用对象，不能维护两套不同Homed/Target状态。候选为MotorPort允许提供受控反馈及外部电流输出、专用对象在硬件层统一接管yaw；最终选择应与B比较，禁止让适配对象和旧轴同时Compute后互相覆盖。

## 阶段与完成条件

待启动 -> 低速找负向端 -> 停流并反向退开 -> 验证已脱离 -> 正向跨越找另一端 -> 停流退开 -> 验证行程 -> 限速回算术中点 -> 连续到位 -> Homed。

- 起点可以是任意位置，包括一开始就在某端。第一端不要求先走固定最小距离；但必须有新鲜反馈，不能用初始无反馈/零速度直接认端点。
- 接触判断联合：控制电流达到限流附近、持续低转速、累计位置在观察窗口内几乎不变。用最新电调反馈校验；不以单帧零转速为端点。
- 每次记录接触计数后立刻解除朝端点的推力，限速反向退让。退让必须以实际反馈证明移动，若卡住不能继续假设端点有效。
- 第二端必须在相反方向，与第一端间有有效行程；两端太近/超限/退让失败均故障，不算成功。两端同时从初始位置不可区分物理左右，先称负向端/正向端，现场核对后才能贴左/右标签。
- 得到均值C=(A+B)/2；位置误差、速度连续满足阈值后才Homed。寻找完成但回中未完成时all_homed=false，自动流程继续等待。
- 运行边界在实测端点内各留退让余量，回中后允许双向点动、松手位置保持。按电机位置/圈数控制和显示，不能显示未经标定的“发射架度数”。

## 首轮参数建议（待B对照定型）

初步使用现有未回零限流848（约0.848A命令），寻找速度转子600rpm、接触观察0.5s、反馈位移窗口不大于转子1/20圈，低转速阈值5rpm；退让转子9圈（在36:1/4mm假设下约1mm）；回中转子600rpm，接近目标减速；到位误差转子1/20圈、低转速5rpm、稳定0.3s。

寻端时间上限每段360s、寻找距离上限转子2880圈（在旧传动假设下320mm），两端最小间距转子45圈（旧假设5mm），最大间距同2880圈。寻端/回中都有限时和反馈距离门禁；这不是已标定的机械参数。若0.848A推不动，不自动提高电流。旧kHomeTimeout=90s不得误杀或被直接全局加大，yaw单独配置。

600rpm按旧传动约1.11mm/s，说明采用转子单位避免单位误用；速度/退让/距离的最终常量须经过B对比与主机动态仿真再写定，不将这些参数作为已批准执行参数。

## 自动回零集成

所有现有手动瞄准组回零、普通4f自动回零、比赛回零入口使用同一yaw启动路径。pitch仍沿用原回零，瞄准组完成需pitch与yaw都完成，随后4f才能启动滑块。`homing`包含yaw找两端、退让、回中全部阶段；`aim_homed`/all_homed/Aimed不能提前放行。

无力、掉线、取消、退出控制或新故障：立即停yaw，未完成测量丢弃，不自动恢复半截寻端；新启动重新测两端。完成后切自动保留当前保持位置与已学习边界；掉线后累计圈数可信性丢失则使回零失效，需要重新完整寻找。滑块受力保持与pitch停机保持不改。

回零忙时不允许手动yaw覆盖；fault reset同时清专用yaw错误。诊断显示阶段、两端计数/圈数、跨度、中点目标、实际位置、cmd/act/rpm及失败原因。
